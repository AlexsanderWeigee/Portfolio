# Portfólio — Alexsander Weigee

## 📖 Contexto

Este projeto é meu portfólio pessoal como desenvolvedor Full Stack.
Ele foi criado com o objetivo de apresentar meus projetos, habilidades técnicas e evolução como programador, de forma visual, organizada e acessível.

O portfólio também serve como um projeto prático de estudo, onde aplico conceitos reais de Front-End, organização de código e responsividade.

A ideia desse projeto surgiu não somente pra mostrar o que eu já fiz, mas também como um desafio pessoal para praticar técnicas que eu nunca tinha usado antes. 

Como ele começou?

Foi a partir dos estudos que eu realizei da plataforma Alura, com o projeto deles que foi passado eu resolvi usar aquele conhecimento para criar o meu próprio, 
realizei algumas pesquisas para buscar inspirações e também para criar o meu de forma única.

---

## 🚀 O que o projeto faz

O portfólio permite:
- Visualizar meus projetos e certificados
- Navegar entre seções de forma dinâmica
- Analisar a organização do layout e dos cards
- Avaliar minha evolução técnica e estilo de código

O foco principal está na experiência visual, organização e clareza da informação.

---

## 🛠️ Como foi feito

Tecnologias utilizadas:
- HTML5
- CSS3 (Flexbox, Grid, responsividade)
- JavaScript (manipulação de DOM, componentes dinâmicos)
- Git & GitHub

O projeto utiliza:
- Estrutura modular
- Geração dinâmica de cards via JavaScript
- Sidebar com toggle
- Layout responsivo para desktop e mobile
